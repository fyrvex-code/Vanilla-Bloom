# 📖 Информация

**Vanilla Bloom** — это современный Minecraft-сервер, ориентированный на качественное ванильное выживание и приятную атмосферу. Наша цель — создать место, где игроки смогут строить, исследовать мир, объединяться в команды и получать удовольствие от честной игры.

### Основная информация

- 🌍 Версия: **26.2**
- ⚡ Ядро: **Paper 26.2**
- 🎮 Режим: Survival
- 💬 Discord-сообщество
- 🔒 Защита аккаунтов
- 🛡️ Античит
- 🎤 Голосовой чат
- 🚀 Высокая производительность
- 🔄 Регулярные обновления
